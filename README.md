# Varenya Estates

Marketing site for Varenya Estates, Mumbai. Vite + React + TypeScript + Tailwind CSS v4.

```sh
npm install
npm run dev      # local dev server
npm run build    # static build to dist/
npm run lint
npm run measure  # typography / nav checks (needs dev server running; first run: npx playwright install chromium)
```

All copy and image references live in `src/content/content.ts`.
